# My Excel Data Analytics Projects

This repository contains two Excel data analysis projects built on a data-related job postings dataset. Together, they demonstrate a range of Excel skills including array formulas, dynamic arrays, XLOOKUP, data validation, Power Pivot, DAX, PivotTables, PivotCharts, slicers, and interactive dashboard design.

---

## Project 1: Data Science Salary Calculator

An interactive Excel dashboard that lets users look up expected salaries based on job title, country, and employment type.
